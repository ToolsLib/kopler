# Kopler 0.1.1

This update improves image capture, image viewing, and working with Markdown alongside Codex, Claude, and other AI desktop apps.

- Pasting an image keeps the capture or editing textarea focused throughout import, preserving the selection and scroll position. Mixed text/image paste places the caret after the inserted text.
- Images open in a separate, larger, resizable window. Fit the image, view it at actual size, zoom in or out, drag to pan, or copy the original image. Use Ctrl/Command + scroll or +/- to zoom, Ctrl/Command+0 to fit, Ctrl/Command+1 for actual size, and Escape to close the viewer.
- Saved notes display Markdown headings, lists, task lists, tables, links, and fenced code. Editing and copying preserve the exact original Markdown source. Markdown clipboard formats are supported alongside plain text. HTML is escaped and remote Markdown images are not fetched.
- Project tabs have a simpler selected state without the top accent line.

`SHA256SUMS.txt` contains checksums for all four packages.

To update from 0.1.0, quit Kopler from Settings or the tray menu, then install the new package. This update keeps the existing application identifier and database format, so notes, projects, images, and drafts remain in the same local data directory. Updates are installed manually.

## Platform status

The new clipboard and image viewer behavior has been verified natively on Windows. Automated coverage includes 32 interface tests, 16 Rust storage/image/clipboard tests, and the release tooling checks. Hosted builds validate Windows, universal macOS, and Linux packages; Linux also runs an X11 launch and shortcut smoke check. The new image viewer still needs native Linux/macOS interaction testing, and macOS runtime validation remains pending.

Windows packages are unsigned. macOS packages use ad-hoc signing and are not Apple-notarized; Gatekeeper can require approval. On Wayland, configure a desktop shortcut to run `kopler --show` because the built-in shortcut uses X11. Mixed text/image clipboard compatibility depends on the receiving app.
