# Kopler 0.1.0

First desktop release candidate: a small local scratchpad for notes, tasks, snippets, and images.

- Capture text or images, paste from the clipboard, or drop image files into the capture box.
- Organize items with project tabs, search, and task completion filters.
- Copy text and images for reuse, edit inline, and undo item deletion.
- Open quickly with a configurable global shortcut; closing saves and hides the window.
- Keep data locally in SQLite, with draft recovery and JSON export/import.
- Choose System, Light, or a neutral charcoal Dark appearance.

## Downloads

| System | Package |
| --- | --- |
| Windows x64 | `Kopler_0.1.0_windows_x64-setup.exe` |
| macOS 14+ — Apple Silicon and Intel | `Kopler_0.1.0_macos_universal.dmg` |
| Linux x64 | `Kopler_0.1.0_linux_x64.AppImage` or `Kopler_0.1.0_linux_x64.deb` |

`SHA256SUMS.txt` contains the checksums for the downloads. The AppImage bundles desktop dependencies and is larger than the DEB/Windows packages. The DEB requires WebKitGTK 4.1 and the other dependencies declared by the package. CI builds Linux packages on Ubuntu 22.04; the optional local build container uses Debian 12. Compatibility still needs a check on the destination distribution.

## Release candidate status

Install the Windows setup executable normally. On macOS, open the DMG and drag Kopler to Applications. On Linux, use your package installer for the DEB, or run `chmod +x Kopler_0.1.0_linux_x64.AppImage` before launching the AppImage.

Windows builds are unsigned. macOS candidates use ad-hoc signing and are not Apple-notarized; Gatekeeper can require approval in Privacy & Security. These builds are for testing before public distribution. macOS runtime validation is still pending. Native Linux checks have covered X11; Wayland testing remains pending.

On Wayland, configure a desktop shortcut to launch `kopler --show`; the built-in global shortcut uses X11. Mixed text/image copying depends on the receiving app. Windows has native clipboard validation; macOS/Linux mixed copying still needs native checks. Storage and exports are not encrypted. Deleted items can be restored with Undo for 10 seconds during the current session.
