# Kopler 0.1.5

The note/task count now appears inside the selected inbox or project tab, beside its name. The separate count badge on the right has been removed. Counts continue to follow the current search and filters.

Tab keyboard navigation, scrolling, and project context menus remain available, including at the minimum window size.

## Update

In Kopler 0.1.2 or newer, open **Settings → Check for updates → Install and restart**. This release uses the existing updater signing key. Kopler verifies the signature and signed version and saves pending work before installing.

Versions earlier than 0.1.2 require a manual installation. Windows/macOS installations and Linux AppImages support in-app updates; package-managed Linux builds use the package download.

## Downloads

| System | Manual installation |
| --- | --- |
| Windows x64 | `Kopler_0.1.5_windows_x64-setup.exe` |
| macOS 14+ — Apple Silicon and Intel | `Kopler_0.1.5_macos_universal.dmg` |
| Linux x64 | `Kopler_0.1.5_linux_x64.AppImage` or `Kopler_0.1.5_linux_x64.deb` |

The release includes signed updater packages, `latest.json`, and `SHA256SUMS.txt`. All files are stored in GitHub Releases, without Actions artifacts.

Windows packages remain unsigned by a Windows publisher; macOS builds are ad-hoc signed and not notarized. These operating-system signatures are separate from the mandatory updater signatures. Native macOS update interaction remains pending.
