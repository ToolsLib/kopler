# Kopler 0.1.3

Delete notes and tasks faster with a modifier-click on the trash icon.

- **Ctrl-click** the Delete icon on Windows/Linux, or **Command-click** on macOS, to delete immediately without confirmation.
- Normal clicks still open the confirmation dialog.
- Pending edits are saved first. Undo remains available for ten seconds, including when deleting an item being edited. Failed saves or deletions keep the item available for retry.
- The Delete tooltip shows the shortcut for your platform.

## Update from 0.1.2

Open **Settings → Check for updates → Install and restart**. The update is signed with the same updater key as 0.1.2; Kopler verifies the signature and signed version before installing and saves your pending work first. Automatic checks also run after startup and every six hours if enabled.

Versions earlier than 0.1.2 require a manual install because they do not contain the updater.

## Downloads

| System | Manual installation |
| --- | --- |
| Windows x64 | `Kopler_0.1.3_windows_x64-setup.exe` |
| macOS 14+ — Apple Silicon and Intel | `Kopler_0.1.3_macos_universal.dmg` |
| Linux x64 | `Kopler_0.1.3_linux_x64.AppImage` or `Kopler_0.1.3_linux_x64.deb` |

The release includes signed updater packages, `latest.json`, and `SHA256SUMS.txt`. Windows/macOS installations and Linux AppImages support in-app updates; package-managed Linux builds use the package download. All files are stored in GitHub Releases, without Actions artifacts.

Windows packages remain unsigned by a Windows publisher, and macOS builds are ad-hoc signed and not notarized. These operating-system signatures are separate from the mandatory updater signatures. Native macOS update interaction and full version-to-version installation testing remain pending.
