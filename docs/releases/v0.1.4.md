# Kopler 0.1.4

Copy text and images without interrupting your work.

- Every image thumbnail has a copy button, so you can copy an individual image without opening its viewer.
- Copying an item, text, or image no longer puts the whole app into Saving mode or disables the editors. Copy uses the current editor contents without forcing a save, even when autosave has failed; normal autosave continues independently.
- On Windows, mixed copy provides plain text and the first image as native PNG/bitmap, without rich HTML. This avoids chat inputs reducing embedded images to “Attached image.” A receiving app may still paste only one representation: the tested Codex input pastes only text. Use **Copy text only** and the image's copy button for separate pastes. Additional images can be copied individually.
- In Settings, **Release notes** is a simple text link below the update buttons.

## Update

In Kopler 0.1.2 or newer, open **Settings → Check for updates → Install and restart**. The update uses the existing updater signing key. Kopler verifies the signature and signed version and saves pending work before installing.

Versions earlier than 0.1.2 require a manual installation. Windows/macOS installations and Linux AppImages support in-app updates; package-managed Linux builds use the package download.

## Downloads

| System | Manual installation |
| --- | --- |
| Windows x64 | `Kopler_0.1.4_windows_x64-setup.exe` |
| macOS 14+ — Apple Silicon and Intel | `Kopler_0.1.4_macos_universal.dmg` |
| Linux x64 | `Kopler_0.1.4_linux_x64.AppImage` or `Kopler_0.1.4_linux_x64.deb` |

The release includes signed updater packages, `latest.json`, and `SHA256SUMS.txt`. All files are stored in GitHub Releases, without Actions artifacts.

Windows packages remain unsigned by a Windows publisher; macOS builds are ad-hoc signed and not notarized. These operating-system signatures are separate from the mandatory updater signatures. Native macOS update interaction and full version-to-version installation testing remain pending.
